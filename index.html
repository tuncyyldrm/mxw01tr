MXW01 Web Terminali projesi hakkında

Bu, Web Bluetooth üzerinden taşınabilir termal yazıcılarla çalışmak için evrensel bir araçtır. MXW01, Lefuxin ve standart ESC/POS protokollerini destekliyoruz. Markdown kullanarak fiş işaretlemeleri oluşturun ve QR kodlarını ve logoları doğrudan tarayıcınızda ekleyin.

Sıkça Sorulan Sorular (SSS):

  • Hangi yazıcılar destekleniyor? Sistem, Grafik Modunda çalışan taşınabilir 58 mm Bluetooth yazıcılar için tasarlanmıştır. Şu anda MXW01 (MTP-II) ve Lefuxin gibi protokoller için destek onaylanmıştır. Standart ESC/POS desteği deneyseldir.
  • Sürücüler gerekli mi? Hayır. Yazdırma işlemi, Web Bluetooth API aracılığıyla Chrome, Edge veya Opera'dan doğrudan yapılır.
  • Bu iOS'ta çalışıyor mu? iPhone'da standart Safari, Web Bluetooth'u desteklemez. Bluefy tarayıcısını kullanmanızı öneririz.
  • Güvenli mi? Evet, yazdırma işlemi yerel olarak gerçekleşir. Verilerinizi sunucuya göndermiyoruz.

About MXW01 Web Terminal

A universal web utility for portable thermal printers via Web Bluetooth API. Supported protocols: MXW01, Lefuxin, and generic ESC/POS. Create receipt layouts using Markdown, insert QR codes, and upload logos directly in your browser.

Frequently Asked Questions (FAQ):

  • Which printers are supported?The system is designed for portable 58mm Bluetooth printers that support direct raster graphics (Graphic Mode). Current implementation includes MXW01 (MTP-II) and Lefuxin protocols. Support for standard ESC/POS is currently experimental.
  • Are drivers required? No. Printing works directly from Chrome, Edge, or Opera browsers via Web Bluetooth API.
  • Does it work on iOS? Standard Safari on iPhone doesn't support Web Bluetooth. Use the Bluefy browser instead.
  • Is it secure? Yes, printing is processed locally. Your data is never sent to our servers.
